VTU Engineering Mini-Project Portfolio

This mini-project, titled "AlgoSocial Analytics", satisfies the course requirements for the Design & Analysis of Algorithms (DAA) laboratory and academic review specifications for VTU Karnataka engineering candidates.

Core Module Implementation

  • String Search: KMP character-matching grid + Rabin-Karp rolling hashes.
  • Dynamic Programming: Word-level LCS highlighting plagiarism overlaps.
  • Data Structures: Memory-based Trie class handling prefix-matched autocomplete lists.
  • Backtracking Recursion: Dynamic graph traversal illustrating active recursion frames and pops.
  • Sentiment Analysis: Lexicon score tokens evaluating positive and negative text polarity.
